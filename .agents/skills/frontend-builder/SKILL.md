# Frontend Builder

Use this skill for frontend implementation tasks.

## Core Directives

1. Prefer modern, fast tooling. Use Vite for new React or vanilla JavaScript apps unless the repo already uses something else.
2. Follow the existing project's framework, component structure, and styling conventions.
3. Use vanilla CSS or CSS Modules unless the user or repo already specifies a styling framework.
4. Build a real usable experience, not a placeholder scaffold, unless the user explicitly asks for a bare scaffold.
5. Verify the app builds and, when a dev server is appropriate, start it and report the URL.

## Architecture

For complex routing, state, or component structure, review `references/frontend_architecture.md`.
