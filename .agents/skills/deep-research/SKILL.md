# Deep Research

Use this skill for research-heavy tasks where the user expects more than a quick answer.

## Workflow

1. Deconstruct the request into the core question, constraints, target audience, and freshness requirements.
2. Formulate 3-5 distinct search queries that cover different angles of the topic.
3. Search broadly, then select authoritative sources for deeper reading.
4. Cross-check important claims across independent sources.
5. Synthesize the result into a concise Markdown report with links to sources.

For larger research tasks, follow `references/research_workflow.md`.

## Output

- Start with an executive summary.
- Group detailed findings by theme.
- Include source links for major claims.
- Call out uncertainty or source conflicts instead of smoothing them over.
