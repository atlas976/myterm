# Deep Research Workflow

## Phase 1: Planning

1. Identify the user's core question, constraints, and target audience.
2. Decide which facts are time-sensitive and must be verified.
3. Generate 3-5 search queries that cover technical, practical, historical, and current angles as relevant.

## Phase 2: Execution

1. Run the search queries and gather a broad set of sources.
2. Prefer primary sources, official documentation, research papers, reputable reporting, and direct project repositories.
3. Read the most relevant sources deeply.
4. Run narrower follow-up searches for gaps, contradictions, or fresh developments.

## Phase 3: Synthesis

1. Outline the answer before drafting.
2. Write in clear, objective language.
3. Cite the sources used.
4. Mark uncertainty explicitly when sources disagree or evidence is incomplete.
