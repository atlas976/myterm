# Beginner Tutorial

This Neovim setup is split into focused Lua modules under `lua/myterm/`.

Use these help topics when changing the config:

- `:help vim.o`
- `:help lua-guide-options`
- `:help vim.keymap.set()`
- `:help lua-guide-autocommands`
- `:help diagnostic-api`
- `:help lazy.nvim.txt`
- `:help lsp`
- `:help lsp-vs-treesitter`
- `:help telescope`
- `:help conform`
- `:help ins-completion`

Tutorial comments are kept out of the runtime config so the actual settings stay
readable.
